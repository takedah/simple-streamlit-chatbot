# simple-streamlit-chatbot

[みのるんさんのStreamlit アプリのハンズオン記事](https://qiita.com/minorun365/items/7ad6c37eb8996e79d631) を参考に、インターネット接続のない閉域の AWS VPC 環境で Streamlit アプリを動かしたデモです。

プログラムのコードはほとんど元記事のとおりで、一部閉域 AWS 環境で動かすために変更を加えたものです。

詳細は以下の Qiita 記事のとおりです。

[閉域内に Bedrock と MCP を使った Streamlit アプリを ECS Express モードでデプロイする](https://qiita.com/takeda_h/items/6c57a34453d01346478d)
